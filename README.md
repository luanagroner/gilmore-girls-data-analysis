# gilmore-girls-data-analysis

# Análise de dados de Gilmore Girls

## Sobre o projeto

Este projeto tem como objetivo explorar e analisar os diálogos da série **Gilmore Girls**, investigando padrões de comunicação e participação dos personagens.

## Objetivos

- Analisar estatisticamente a distribuição e a frequência das falas por personagem e temporada;
- Investigar tendências e mudanças na participação dos personagens ao longo das sete temporadas;
- Comparar a participação dos personagens entre temporadas, identificando padrões e variações;
- Analisar como as falas estão distribuídas entre os personagens, identificando os que possuem maior participação nos diálogos;
- Analisar a extensão dos diálogos, considerando a quantidade de palavras por fala;
- Desenvolver visualizações e indicadores para apresentar os resultados e principais insights.


## Tecnologias utilizadas

- Python
- Pandas
- SQL
